# Himanshu Singh - Resume Website

This is a responsive, modern, and interactive resume website for **Himanshu Singh**, showcasing personal information, technical skills, projects, leadership experiences, and contact details.

## 🌐 Live Demo

👉 [Visit Portfolio](https://himanshuacoder.github.io/Resume-Website/)  
👉 [Visit Personal Portfolio](https://himanshuacoder.github.io/Portfolio-Website/)

---

## 📄 Description

The resume website was created to serve as an online, interactive résumé and project showcase. It features responsive layouts, animated skill cards, and detailed project summaries—all designed to reflect professional web development practices.

---

## 🛠️ Built With

- **HTML5** – Semantic structure
- **CSS3** – Custom styles and transitions
- **Responsive.css** – Media queries for mobile responsiveness
- **Font Awesome** – Icons
- **JavaScript** – Smooth scrolling and mobile menu toggle

## 🧩 Project Sections

- **Home/Hero Section**: Introduction with name, title, and profile picture.
- **About Section**: Educational background and personal hobbies.
- **Skills Section**: Visual presentation of technical expertise.
- **Projects Section**: Highlights of development projects including:
  - Blog Website
  - Crowd Funding Website
  - Gym Website
  - Landing Page
  - Sign-Up Form Template
  - Indian Flag CSS Art
- **Experience Section**: Leadership and mentoring initiatives.
- **Contact Section**: Form with fields and linked social media icons.

## 🧾 Resume Integration

This project is an extension of the résumé of **Himanshu Singh**. It transforms the resume into a web-based interactive format, making it easier for recruiters to view and access qualifications, skills, and projects dynamically.
